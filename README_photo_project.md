
# Проект: Поиск изображений по текстовому описанию

## Описание проекта

Разработана демонстрационная система, определяющая релевантность пары *текст — изображение*. Задача — создать модель, которая получает векторные представления изображений и текстов и выдаёт значение от 0 до 1, отражающее степень соответствия.

Решение может применяться в системах рекомендаций, контентных поисковых движках и мультимодальных продуктах.

## Постановка задачи

- Обучить модель, которая оценивает релевантность текста и изображения.
- Использовать метки, полученные от краудсорсеров и экспертов, как основу для таргета.
- Выстроить пайплайн получения эмбеддингов для изображений и текста.
- Протестировать модель на паре `текст — изображение` из тестовой выборки.

## Описание данных

Проект использует следующие файлы:

- **`train_dataset.csv`** — содержит пары `image_id`, `text_id`, `text`, до 5 описаний на изображение.
- **`CrowdAnnotations.tsv`** — краудсорсинговые оценки релевантности (0–1), число подтверждений и опровержений.
- **`ea.tsv`** — оценки экспертов по шкале от 1 (несоответствие) до 4 (полное соответствие).
- **`test_queries.csv`** — тестовые пары `query_id`, `text`, `rel_img`.
- **`train_images/`, `test_images/`** — изображения.

## Как решалась задача

- Выполнена агрегация экспертных оценок (метод большинства).
- Обнаружены и удалены неоднозначные пары с равномерным распределением оценок.
- Объединены краудсорсинговые и экспертные данные.
- Получены эмбеддинги изображений и текстов с помощью модели CLIP (HuggingFace).
- Обучена модель предсказания соответствия (регрессия / классификация).
- Реализовано сравнение и ранжирование изображений по запросу.

## Использованные технологии

- `Python`, `Pandas`, `OpenCV`
- `PyTorch`, `CLIP`, `TorchMetrics`
- `HuggingFace Transformers`
- `Jupyter`, `Matplotlib`

## Результаты

- Построен полный пайплайн text-to-image relevance scoring.
- Использована модель CLIP для извлечения признаков.
- Оценка релевантности на тестовых данных проводилась по метрикам MAE / RMSE.
- Обоснован выбор метки (по экспертной и краудсорсинговой разметке).
- Модель позволяет найти наиболее подходящие изображения под текстовый запрос.

## Выводы

- Использование агрегированных экспертных оценок позволяет точнее маркировать данные.
- CLIP успешно решает задачу извлечения общих признаков из разных модальностей.
- Разработанный пайплайн можно расширить до ранжирования или мультимодальной генерации.
